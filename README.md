# 🏥 Company Health – Website de Produtos Digitais para Saúde

📸 **[Ver Galeria do Projeto](./Gallery.md)**

**Company Health** é um website moderno, profissional e focado em conversão, desenvolvido para **empresas da área da saúde**, **produtos digitais**, **serviços médicos** e **soluções empresariais**.

O projeto apresenta um design limpo, confiável e orientado para resultados, com seções estratégicas que destacam **produtos**, **benefícios**, **preços**, **equipa**, **testemunhos** e **chamada para ação**.

Ideal para empresas que desejam transmitir **credibilidade, profissionalismo e inovação**.

## ✨ Visão Geral

Este website foi pensado para apresentar produtos e serviços de saúde de forma clara, acessível e profissional, oferecendo uma excelente experiência ao utilizador e facilitando a tomada de decisão.

O layout é moderno, responsivo e otimizado para **negócios digitais**, **plataformas de saúde**, **startups médicas** e **empresas corporativas**.

## 🚀 Como Usar

### 1️⃣ Clonar o repositório

```bash
git clone https://github.com/solipa365-templates/company-health.git
```

### 2️⃣ Entrar no diretório

```bash
cd company-nextjs
```

### 3️⃣ Instalar dependências

```bash
npm install
# ou
yarn install
```

### 4️⃣ Iniciar o servidor de desenvolvimento

```bash
npm run dev
# ou
yarn dev
```

Acesse em:
👉 http://localhost:3000
